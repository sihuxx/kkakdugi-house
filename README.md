# 꺅두기 하우스 🍀

꺅두기를 **애기부터 어른까지 키우는** 웹 게임. 집에서 밥 주고 씻기고 재우면 두기가 자라고,
현관으로 나가 **배달 · 광산 · 미아 찾기 · 택배 포장 · 캐치마인드 알바**를 뛰어 번 돈으로 뽑기를 돌리고 집을 넓혀갑니다.

브라우저만 있으면 돌아가고, 설치할 것도 서버도 없습니다.

```
index.html 을 브라우저로 더블클릭
```

## 놀이 흐름

**알바로 벌기 → 뽑기로 새 두기 → 좋은 모습이 알바비를 올림 → 더 많이 뽑기**

집에서 돌보기는 그 사이를 이어주는 부분이에요. 잘 돌본 두기가 알바도 잘합니다.

1. 두기를 **문질러 쓰다듬으면** 마음이 오릅니다 (아무 때나, 공짜)
2. **방 안의 물건을 직접 눌러서** 돌봐요 — 밥그릇·대야·공·침대·화분, 먼지는 먼지를 누르면 청소
   - **밥 주기** 음식 카드를 골라 먹이기 (두기마다 숨은 최애 음식이 있어요 · 맞히면 마음 두 배)
   - **씻기기** 마우스로 문질러 때 지우기
   - **놀아주기** 공을 당겼다 놓아 던지면 두기가 물어옵니다
   - **재우기** 침대로 걸어가 눕고 화면이 어두워져요
   - **물 주기** 화분이 단계별로 자라고, 꽃이 피면 클로버 120
   - **청소하기** 먼지를 문질러 쓸기
3. 현관(`E`)으로 나가면 **정원**이에요 — 가게 · 뽑기 기계 · 알바 게시판이 있습니다
   (정원의 **알바 게시판** 앞에서 고릅니다) → **클로버 + 마음**
4. 일하고 오면 배고프고 지저분해져요. 두기가 먼저 조르기도 합니다(들어주면 보너스 클로버)
5. 클로버로 **가구·소모품·벽지**를 사고 **집을 넓히고**(정원의 가게), **새 모습**을 뽑고(정원의 뽑기 기계)
   옷장에서 갈아입혀요. 벽의 **공구 걸이**를 누르면 가구를 끌어서 원하는 자리에 놓을 수 있습니다
6. **오늘의 할 일** 3개로 보너스 클로버
7. 자리를 비우면 **시간이 흐릅니다** — 돌아오면 그동안 있었던 일을 알려줘요
8. **날씨**가 매일 바뀌고(맑음·흐림·비·눈), 궂은 날은 시급이 올라요
9. 가끔 **손님 두기**가 놀러 옵니다. 간식을 주면 선물을 두고 가요
10. 벽의 **사진첩**을 누르면 지금 화면을 그대로 **사진**으로 남길 수 있어요 (최대 12장)

### 두기 레벨

뭘 하든 경험치가 쌓입니다 — 알바, 돌봄, 뽑기, 할 일. 최대 **Lv 60**.

- 레벨 하나당 **알바비 +1.2%** (최대 +60%)
- 레벨마다 클로버, 5의 배수마다 더 크게, 10의 배수마다 간식까지
- 상단바의 초록 막대가 다음 레벨까지 남은 양이에요

### 알바 랭크

알바마다 따로 올라갑니다. 많이 해본 알바일수록 높아져요.

견습 → 브론즈(3번) → 실버(9번) → 골드(20번) → 플래티넘(36번) → 다이아(60번) → **마스터(95번)**

### 순위표 (로그인했을 때)

알바 모달 아래에 전체 순위가 뜹니다. 알바별 상위 20명과 내 등수.
점수는 브라우저가 세는 것이라 **위조를 완전히는 막지 못합니다** —
어디까지 막았고 뭘 못 막았는지 [SECURITY.md](SECURITY.md) 9장에 적어뒀어요.

### 진행은 두 갈래 — 마음 레벨과 알바 경력

**마음 레벨 (Lv1~10)** — 돌보고 쓰다듬을 때마다 차오르는 메인 진행. 레벨이 오르면 두기가
혼잣말을 하고, 특별 가구(쿠션·해먹·트로피)를 선물로 받고, 알바 시급이 올라갑니다.

**알바 경력** — 알바마다 따로 쌓입니다. 뛸수록 시급이 오르고, 배달은 새 코스가 열려요.

### 스탯 4가지

배부름 · 깨끗함 · 기분 · 기운. 평균이 **컨디션**이고, 시급 배율 =
(0.62 + 0.38 × 컨디션) × 마음 보너스 × 가구 보너스 × 경력 보너스.

두기는 가끔 **먼저 조릅니다**(배고파요 / 심심해 / 졸려요…). 말풍선이 뜨고 해당 돌봄 버튼에 `!`가
붙는데, 그걸 해주면 보너스 클로버 35와 마음이 올라갑니다. 가만히 두면 **혼자 돌아다니며** 낮잠을
자거나 티비를 봅니다. 방이 더러워지면 먼지가 굴러다녀요.

### 집 업그레이드

돈을 모으면 이사할 수 있어요. 방이 넓어지고 벽지·바닥·조명이 바뀌며 놓을 수 있는 가구도 늘어납니다.

| 집 | 값 | 달라지는 것 |
| --- | --- | --- |
| 낡은 방 | 처음부터 | 좁고 벽지가 들떴어요. 알전구 하나 · 가구 6칸 |
| 아늑한 집 | 2,400 | 도배·마루 새로, 창문과 커튼 · 가구 11칸 |
| 넓은 집 | 7,000 | 창문 둘에 천장 몰딩, 펜던트 조명 · 가구 16칸 |

방은 **주방 · 거실 · 침실** 세 구역으로 나뉘고, 가구는 자기 구역에 자동으로 자리를 잡습니다.
마음에 안 들면 꾸미기 모드에서 끌어다 옮기세요 (저장됩니다).

### 가구

상점에서 클로버로 삽니다. 사면 집에 알아서 자리를 잡고 효과도 붙어요 — 러그(기분 +2),
램프(잘 때 기운 +4), 책장(경험치 +8%), 낮은 탁자, 티비(놀아줄 때 기분 +5), 냉장고(밥 배부름 +6),
생일 케이크(경험치 +15%), 장난감 피아노(알바비 +8%), 소파, 액자·벽시계(알바비 +5%),
장식 깃발, 포스터, 작은 창문. 큰 가구는 집을 넓혀야 놓을 수 있습니다.

## 광장 — 여럿이 모이는 곳

정원 오른쪽 끝 **아치문**으로 들어갑니다. 접속 중인 사람들의 두기가 **실제로 같이 걸어다녀요.**

| 할 수 있는 것 | 설명 |
| --- | --- |
| 같이 걷기 | 남의 두기는 받은 위치 사이를 이어 그려서 부드럽게 움직여요 |
| 명함 | 남의 두기를 누르면 이름 · Lv · 모습 등급 · 도감 N/31 · 알바 랭크 · 최고 기록 |
| 인사 | 정해진 6개(`꺅!` `반가워` `♥` `?` `축하해` `잘 가`) 중 골라 말풍선 |
| 캐치마인드 천막 | 열려 있는 방 목록 — **코드 없이** 바로 들어가기 |

**왜 자유 채팅이 없나** — 보내는 게 **번호뿐**이면 욕설도, 개인정보도, 스크립트도
낄 자리가 없습니다. 캐치마인드는 정답을 쳐야 하니 자유 입력이 필수지만, 광장은 아니에요.

**한 광장 20명.** 넘치면 다음 광장(`MADAN4` → `MADAN6` → `MADAN7`)으로 들어갑니다 —
사람이 늘수록 주고받는 양이 인원의 **제곱으로** 커지기 때문입니다.

오가는 값은 이게 전부예요.

- **위치** `{x, y, 바라보는 쪽}` — 0.18초에 한 번, 움직였을 때만
- **인사 번호** 0~5
- **presence** 이름 · 모습 id · 레벨 · 도감 수 · 알바 랭크 · 최고 기록 · 내가 연 방 코드

받은 좌표는 전부 **0~1 로 잘라서** 씁니다. 남이 `x: 999` 를 보내도 화면이 깨지지 않아요.
모르는 키에서 온 움직임은 버리고, 범위 밖 인사 번호도 버립니다.

**클로버 선물·교환은 일부러 안 넣었습니다** — 서버 검증 없이는 클로버 복제가 그대로 가능하고,
막아도 부계정 자전거래로 랭킹이 무너집니다.

## 돌봄은 '서브'입니다 (빠지진 않아요)

두기 키우기는 **메인이 아니라 알바비 보정**으로 둡니다. 버튼 줄로 화면을 차지하는 대신,
**방 안의 물건을 직접 누르는** 방식이에요.

| 누르는 것 | 하는 일 |
| --- | --- |
| 밥그릇 | 밥 주기 |
| 대야 | 씻기기 |
| 공 | 놀아주기 |
| 침대 | 재우기 |
| 화분 | 물 주기 |
| 바닥의 먼지 | 청소하기 |

두기가 뭔가 조르면 **그 물건이 분홍으로 두근거립니다.** 찾아다닐 필요가 없어요.

**왜 안 뺐나** — 이미 보상에 연결돼 있기 때문입니다.

- 컨디션 0% → 알바비 **×0.80** · 100% → **×1.10** (최대 **+37%** 차이)
- 쓰다듬기·돌봄마다 경험치도 조금씩 들어와요

문제는 "효과가 없는 것"이 아니라 **"효과가 안 보이는 것"** 이었습니다. 그래서:

- 상태바에 **컨디션 한 칩** — 옆에 `알바비 ×1.08` 이 같이 붙습니다
- 알바 결과에 **`컨디션 92% 덕에 +58`** 이 숫자로 찍힙니다
- 수치가 줄어드는 속도를 **1/3 정도 늦췄어요** — 숙제처럼 느껴지지 않게

## 메뉴는 어디에 있나

화면 위쪽 버튼 줄을 **없앴습니다.** 모든 메뉴는 두기가 걸어가서 여는 **사물**이에요.
누르면 두기가 그 앞까지 가서 열어줍니다.

**집 안**

| 사물 | 열리는 것 |
| --- | --- |
| 벽의 사진첩 | 앨범 — 방 사진 찍기 |
| 옷장 | 두기 도감 · 모습 갈아입기 |
| 현관문 | 정원으로 |

**정원**

| 사물 | 열리는 것 |
| --- | --- |
| 우리 집 | 집으로 |
| 가게 | 상점 |
| 뽑기 기계 | 뽑기 |
| 알바 게시판 | 알바 고르기 |
| 명예의 전당 | 랭킹 — 내 최고 기록 · 알바 랭크 · 전체 순위표 |
| 아치문 | **광장으로** |

**☰ (오른쪽 위)** — 세계에 두기엔 애매한 시스템 메뉴만 모았습니다.

오늘의 할 일 (남으면 빨간 점) · 꾸미기 · 로그인/내 계정 · 설정

오른쪽 아래 작은 `⛶` 만 버튼으로 남았습니다 (전체화면).

위쪽 상태바도 **칩 네 개**로 줄였어요 — `이름·레벨·마음`, `컨디션 %`, `날씨·시간`, `클로버`.
네 수치(배부름·깨끗함·기분·기운)는 **컨디션 칩을 눌렀을 때만** 펼쳐집니다.

## 알바 ① 배달 (매번 다른 길)

쿠키런 같은 2D 횡스크롤 러닝. 배달 가방을 메고 달립니다.
**매 판 배경과 길이 새로 정해집니다** — 동네 골목 · 공원 길 · 바닷가 · 노을 길 · 밤 골목 다섯 가지 배경 중
하나가 뽑히고, 코스 덩어리 순서도 섞이고, 장애물 밀도와 속도도 조금씩 달라져요. 같은 판은 두 번 안 나옵니다.

| 조작 | 하는 일 |
| --- | --- |
| `Space` / `↑` / `W` | 점프 (공중에서 한 번 더 누르면 2단) |
| `↓` / `S` | 슬라이드 — 덩굴 밑을 지나갑니다. 공중에서 누르면 쿵 내려찍기 |
| `E` | 스킬 (게이지가 다 차면) |
| `Esc` | 그만두고 집으로 |

**동전**을 주우면 점수와 스킬 게이지가 차고, 체력 클로버 3개가 다 떨어지면 배달 실패.
배달할 집까지 도착하면 보너스를 받습니다. 덩굴은 점프로 넘을 수 없으니 **슬라이드**로 지나가세요.

**모습마다 스킬이 다릅니다** — 돌진(무적·장애물 파괴) / 폭신 점프(3단) / 동전 자석 /
둥실둥실(활공) / 느긋느긋(느리게·동전 2배).

## 알바 ② 두기 광산 (마을 뒷산)

한 칸씩 파 내려갑니다. **언제든 올라올 수 있고**, 안 올라오고 계속 파다 무너지면
들고 있던 클로버를 전부 잃어요. 반사신경이 전혀 필요 없는 대신 **배짱이 필요한** 알바입니다.

- `스페이스` 더 파기 · `ESC` 올라가기 (버튼으로도 됩니다)
- **다음 칸이 무너질 확률을 화면에 띄웁니다** — 몰라서 지는 게 아니라 알면서도 욕심내다 져야 재밌으니까요
- 처음 5칸은 안전. 그 뒤로 한 칸마다 위험이 2.3%씩 올라갑니다 (최대 40%)
- **지지대**를 주우면 무너짐을 한 번 막아줍니다
- **금이 간 칸**을 파면 바로 다음 한 칸만 특히 위험해져요 (+11%)
- 땅이 흙 → 돌 → 푸른 암반 → 수정층으로 바뀝니다. **30m 바닥**까지 가면 벌이가 1.5배

### 어디서 멈추는 게 좋을까 (4만 판 돌려본 결과)

| 멈추는 깊이 | 평균 벌이 | 무너질 확률 |
| --- | --- | --- |
| 10m | 421 | 21% |
| 14m | 588 | 41% |
| **16m** | **614** ← 가장 이득 | 52% |
| 21m | 515 | 76% |
| 30m 바닥 | 263 | 97% (성공하면 5,529) |

14~18m가 거의 비슷해서 **딱 하나의 정답이 없게** 맞춰뒀습니다. 안전하게 10m에서
끊어도 괜찮고, 욕심내도 괜찮아요.

## 알바 ③ 미아 찾기 (광장 안내소)

사람들 틈에서 **지목된 두기 한 마리**를 찾아 누릅니다. 반사신경이 아니라 눈으로 하는 알바예요.

- 40초로 시작 · 맞히면 **+2.6초**, 헛짚으면 **−5.0초**
- 라운드마다 사람이 3명씩 늘어납니다 (최대 54명)
- 연속으로 맞히면 보너스가 붙어요
- **도감에 있는 두기**가 나오면 이름까지 보여주고 **점수 +30%**

> 그림을 새로 만들지 않았습니다 — 이미 있는 31종을 그대로 깔아요.
> 그래서 뽑기로 많이 모을수록 "저건 누구" 가 빨리 보입니다.

## 알바 ④ 택배 포장 (물류 창고)

8×8 상자에 블록 세 개가 차례로 주어집니다. 끌어다 넣고, **가로나 세로 한 줄이 꽉 차면**
그 줄이 비워지면서 점수가 돼요. 셋 다 들어갈 자리가 없으면 끝.

- **시간이 가지 않습니다** — 급할 이유가 없어서 머리로 하는 알바가 됩니다
- 한 번에 여러 줄을 지울수록 점수가 **제곱으로** 커져요 (2줄 = 4배)
- 연달아 지우면 연속 보너스
- 놓을 자리를 비추면 **터질 줄이 미리 빛납니다**

## 알바 ⑤ 두기 캐치마인드 (여럿이 · 실시간)

한 명이 그리고 나머지가 맞히는 알바입니다. **2~8명**, 친구와 **방 코드 6자리**를 주고받아
들어갑니다. 한 사람씩 돌아가며 2바퀴 그려요.

- 출제자는 단어 3개 중 하나를 고릅니다 (키보드 `1`·`2`·`3` 으로도)
- 75초 안에 그리고, 나머지는 오른쪽 칸에 정답을 적습니다
- 시간이 흐르면 힌트가 열려요 — **글자 수 → 초성 → 첫 글자**
- 빨리 맞힐수록, 일찍 맞힐수록 점수가 큽니다. 출제자는 맞힌 사람 수만큼 받아요
- 색 11가지 · 굵기 3가지 · 지우개 · 되돌리기(`Z`)

**정답 단어는 그리는 사람 화면에만 있습니다.** 방에 뿌리지 않아서, 누가 맞혀도
그 글자가 채팅에 뜨지 않아요. 자세한 건 [SECURITY.md](SECURITY.md) 8장에 적어뒀습니다.

> 서버(`js/config.js`)를 설정하지 않으면 이 알바는 안내만 띄우고 넘어갑니다.

## 뽑기와 옷장 — 이 게임의 중심

정원의 **뽑기 기계**에서 클로버로 새 **모습**을 뽑습니다.
1회 110, 10연차 1000. 전부 **31종**이에요.

- **하루 한 번 무료** — 뽑기 화면에 무료 버튼이 살아 있으면 아직 안 쓴 거예요
- **천장 세 겹** — 100번 안에 진귀 이상, 400번 안에 전설, 1500번 안에 울트라초수퍼전설이 확정.
  몇 번 남았는지 화면에 보입니다
- **겹쳐도 손해가 아님** — 흔함 55 · 귀함 130 · 진귀 340 · 전설 900 클로버로 돌려받아요
- **10연차에는 귀함 이상이 하나 확정**

### 모은 게 실제로 쓸모 있어요

뽑은 모습은 보기만 좋은 게 아니라 **알바비를 올려줍니다.**

| 무엇 | 보너스 |
| --- | --- |
| 지금 입은 모습 — 흔함 / 귀함 / 진귀 / 전설 / 울초전 | +3% / +7% / +13% / +22% / **+35%** |
| 도감 수집 — 한 종류당 | +1% (최대 +30%) |

전부 모으고 울트라초수퍼전설을 입으면 **알바비가 +65%**. 알바 화면과 뽑기 화면에
지금 받고 있는 보너스가 표시됩니다.

### 도감 보상

3종 200 · 5종 400 · 9종 800 · 13종 1,300(+간식) · 17종 1,800 ·
22종 2,600(+간식) · 27종 4,000 · **31종 12,000**

| 등급 | 확률 | 종류 |
| --- | --- | --- |
| 흔함 ★ | 78% | 11종 |
| 귀함 ★★ | 19.7% | 11종 |
| 진귀 ★★★ | 1.7% | 5종 |
| **전설 ★★★★** | **0.5%** | **2종** |
| **울트라초수퍼전설 ★★★★★** | **0.1%** | **1종 — 귀여운 두기** |

**울트라초수퍼전설** — 맨 위 한 칸에 **귀여운 두기 한 마리만** 들어 있습니다. 1000번에 한 번 꼴이에요.
입고 다니면 알바비 **+35%** — 모든 모습 중 제일 높습니다.

**천장 세 겹** — 100번 안에 진귀 이상, 400번 안에 전설, **1500번 안에 울트라초수퍼전설**이 반드시 나옵니다.
위 등급이 나오면 아래 천장도 같이 풀려요. 10연차에는 귀함 이상이 하나 확정이고,
겹치면 클로버로 돌려받습니다(흔함 18 · 귀함 45 · 진귀 140 · 전설 400 · 울초전 1,200).

> 환급 기댓값은 1회당 약 29 클로버 — 뽑기 값(100~110)보다 한참 낮습니다.
> **뽑으면 뽑을수록 클로버는 줄어요.** 늘리는 건 알바, 쓰는 건 뽑기.
뽑은 모습은 **옷장**에서 갈아입힙니다 — 두기는 한 마리, 모습만 바뀝니다.
도감을 모으면 클로버와 간식을 받습니다(5·9·13·17종).

## 계정 (선택)

로그인하면 세이브가 서버에 저장돼서 **다른 컴퓨터에서도 이어할 수 있어요.**
설정하지 않으면 로그인 없이 이 브라우저에만 저장됩니다.

- 비밀번호는 이 게임이 저장하지 않습니다 — 인증 서버가 해시해서 보관해요
- 접근 토큰은 메모리에만, 재발급 토큰은 기본이 탭을 닫으면 사라지는 저장소입니다
- "로그인 유지"를 켠 사람만 기기에 남습니다

설정법과 보안 설계는 **[SECURITY.md](SECURITY.md)** 에 정리해뒀습니다.
`supabase/schema.sql` 을 Supabase SQL Editor에 붙여넣고, `js/config.js` 에 주소와 키를 넣으면 끝이에요.

### GitHub Pages로 올리기

1. 이 폴더를 통째로 저장소에 올립니다
2. 저장소 → **Settings → Pages**

4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다

## 고치고 싶을 때

- **가구 추가** — `js/grow.js`의 `FURNITURE`에 한 줄 넣고(`row:1`이면 벽쪽 줄, `need:1`이면
  아늑한 집부터), `js/home.js`의 `drawFurn()` 스위치에 그리는 법을 추가하면 상점에 자동으로 나옵니다.
  자리는 `layoutHome()`이 줄마다 고르게 잡아줍니다
- **집 단계 추가** — `js/grow.js`의 `HOUSES`에 한 줄 (넓이·높이·가구 자리 수)
- **배달 배경 추가** — `js/run.js` 위쪽 `THEMES`에 한 줄 (하늘·언덕·덤불·흙·풀 색)
- **먹이·소모품 추가** — `FOODS` / `ITEMS` 에 한 줄
- **돌봄 종류 추가** — 같은 파일의 `CARE`에 넣고, 가구의 `act`를 그 이름으로
- **런 맵 고치기** — `js/run.js` 위쪽 `CHUNK`(덩어리 하나)와 `MAP`(이어 붙이는 순서).
  땅과 땅 사이를 비우면 구덩이가 됩니다. 한 번 점프로 높이 약 200 · 거리 330을 넘어요
- **선 굵기** — 게임 안의 모든 선은 `js/boot.js`의 `LW()` 하나로 정해집니다
